# reboop-eslint

ESLint plugin intended to require HTTP requests through the configured reboop client.

This package is a development scaffold. Rules and shared configurations are not implemented yet.
It currently exports an empty module. JavaScript and TypeScript declarations are built together.

ESLint 10.4 or newer is the initial supported peer dependency.

See the [repository](https://github.com/mutating/reboop) for development and release instructions.
